# История изменений ChiyuriPlayer

## 0.4.17 — 6 ноября 2026

**Статус сборки:** опубликован GitHub Release v0.4.17; workflow #120 завершился успешно. Unit-тесты пройдены, подписанный APK собран, проверка подписи и версии APK пройдена, артефакт загружен и релиз опубликован. API GitHub Releases/latest возвращает v0.4.17.

- Свёрнутый мини-плеер: прозрачность 70%; развёрнутый мини-плеер: 0%.
- Прозрачность основных поверхностей интерфейса — 5%.
- Размытие фонового изображения уменьшено до 1 dp.
- Основной фон масштабируется с сохранением пропорций.
- Обложка активного трека заменяет запасной фон; если обложки нет, показывается встроенное фоновое изображение.
- Аудиовизуализатор использует цветовой спектр.

**APK SHA-256:** `c7a3fdb621d036f5cac2276b22735b7c43524abf07d4cfd91f349d44cd38411b`.

**Не подтверждено на реальном устройстве:** визуальная проверка прозрачности и переходов между встроенным фоном и обложкой на разных экранах и версиях Android; получение и установка обновления через Центр обновлений на физическом устройстве.

## 0.4.18 — подготовка следующего обновления

**Статус:** изменения внесены в workflow и ожидают сборки; GitHub Release ещё не опубликован. Планируемый versionCode: 328.

- В общем списке музыкальной библиотеки текущий воспроизводимый трек будет выделяться контрастной рамкой, фоном и пометкой «СЕЙЧАС ВОСПРОИЗВОДИТСЯ».
- В очереди воспроизведения текущий трек получит такое же заметное выделение.
- При каждом открытии очереди список автоматически прокручивается к текущему треку. После автоматического перехода пользователь может свободно прокручивать очередь вручную.
- Позиционирование выполняется только при открытии окна очереди, поэтому последующая ручная прокрутка не будет постоянно сбрасываться.

**Проверки до публикации:** точечная проверка патча исходного Kotlin-кода, unit-тесты, сборка подписанного APK, проверка versionName/versionCode и подписи. Реальное поведение прокрутки и подсветки потребуется проверить на Android-устройстве.
