# История изменений ChiyuriPlayer

## 0.4.7 — 4 ноября 2026

**Статус сборки:** опубликован GitHub Release v0.4.7; workflow #87 завершился успешно.

- Сохранено исправление отмены фоновой загрузки обновления: закрываются активные потоки, разрывается HTTP-соединение и удаляется незавершённый APK.
- Отмена обрабатывается также во время проверки SHA-256 и сертификата подписи.
- Сохранены оформление системных медиакнопок и совместимость записи метаданных с SAF-поставщиками, не поддерживающими режим `rwt`.
- Подписанный APK опубликован в обычном GitHub Release.

**SHA-256 APK:** `3a848c18f84d95aaa1d88b7fce0314c8fc053aaabea51fb14a8245389d9b639f`.

**Не подтверждено на реальном устройстве:** отмена загрузки на медленном соединении, уведомления на разных версиях Android, запись метаданных через различные SAF-провайдеры и корректность внешних источников текстов. Отдельно продолжается проверка кнопки сохранения редактора метаданных.

## 0.4.8 — подготовка релиза

**Статус:** версия настроена в workflow как `0.4.8` / versionCode `318`; GitHub Release ещё не опубликован.

- Продолжается исправление редактора метаданных: видимый статус сохранения, блокировка повторного нажатия, сообщения об ошибках и безопасное восстановление исходного файла.
- После исправлений обязательны unit-тесты, сборка release APK, проверка версии и сертификата подписи.
- Публикация будет считаться завершённой только после успешного обычного GitHub Release.

## 0.4.6 — 4 ноября 2026

**Статус сборки:** опубликован GitHub Release v0.4.6; workflow #83 завершился успешно.

- Усилена отмена фоновой загрузки обновления: при отмене явно закрываются активные входной и выходной потоки, разрывается HTTP-соединение и удаляется частичный APK.
- Добавлена очистка скачанного APK при отмене во время проверки SHA-256 или сертификата подписи.
- В CI добавлена отдельная проверка наличия критических элементов отмены: закрытия потоков, отключения соединения, удаления файла и регистрации обработчика системного уведомления.
- Сохранены фоновая задача WorkManager, отображение прогресса и команда отмены из приложения и системного уведомления.

**Проверено в CI:** workflow #83 успешно прошёл unit-тесты, сборку подписанного APK, проверку подписи и публикацию.

**Не подтверждено на реальном устройстве:** мгновенное прекращение загрузки при медленном или зависшем сетевом соединении, удаление частичного файла во всех сценариях отмены и сохранение загрузки при переключении вкладок и в фоне. Нужен практический тест на Android.


Здесь отдельно отмечаются изменения исходников, результаты автоматической сборки и ограничения проверки. Успешный CI не считается подтверждением работы на реальном устройстве.

## 0.4.5 — 4 ноября 2026

**Статус сборки:** опубликован GitHub Release; последний workflow #79 завершился успешно.

- Центр обновлений переведён на фоновую задачу WorkManager с прогрессом загрузки.
- Добавлена отмена загрузки из Центра обновлений и системного уведомления; при отмене сетевое соединение закрывается, незавершённый APK удаляется.
- Для загрузки обновления проверяются SHA-256 и сертификат подписи до предложения установки.
- Добавлен отдельный канал и оформление системного уведомления воспроизведения Media3.
- Запись метаданных через SAF дополнена переходом с режима rwt на w для поставщиков документов, которые не поддерживают rwt; сохраняются проверка записанных данных и попытка отката.
- В Центр обновлений выведена версия из BuildConfig.VERSION_NAME и BuildConfig.VERSION_CODE.
- Расширен поиск текстов песен: LRCLIB, lyrics.ovh, результаты Deezer, SyncLRC и интеграция LiriQo, агрегирующая несколько каталогов. Количество реально работающих источников и качество совпадений ещё требуют проверки на наборе реальных треков.
- Добавлено отображение синхронизированных/обычных текстов в расширенном мини-плеере.

**Проверено в CI:** unit-тесты, сборка release APK, проверка подписи, проверка manifest version и публикация артефакта. Workflow #79 завершился с success.

**Не подтверждено на реальном устройстве:** фактическая отмена загрузки из обоих интерфейсов, сохранение загрузки при переключении вкладок и в фоне, отображение системных уведомлений на разных версиях Android/оболочках, запись метаданных на проблемном SAF-провайдере и корректность ответов всех внешних lyric API. Эти сценарии нуждаются в пользовательском тестировании.

## Предыдущая подтверждённая кодовая база

### Полноэкранное видео — внутренняя сборка CI #172

- Добавлен полноэкранный режим видео.
- Обычный и полноэкранный интерфейсы используют один экземпляр PlayerView.
- Системные панели скрываются во время просмотра и временно показываются жестом.
- Добавлены кнопка выхода и обработка системной кнопки «Назад».

### PR #3 — встроенные тексты песен, синхронизация и пресеты эквалайзера

- Чтение MP3 ID3 USLT, SYLT и TXXX LYRICS_SYNCED.
- Чтение FLAC Vorbis comments LYRICS и LYRICS_SYNCED.
- Чтение M4A/MP4 ©lyr и freeform LYRICS_SYNCED.
- Встроенные тексты имеют приоритет перед поиском LRCLIB.
- Индивидуальная поправка синхронизации для URI трека: ±10 000 мс, шаг 100 мс.
- Семь пресетов: Flat, Bass, Pop, Rock, Classical, Jazz и Vocal.
- Добавлены unit-тесты.

**Известное ограничение:** текущий M4A/MP4 reader ограничен первыми 16 МиБ файла. Если атом moov находится в конце большого файла, текст может не обнаружиться.

### PR #1 — запись ID3-метаданных MP3

- Запись ID3 TIT2, TPE1, TALB, TDRC, USLT и APIC.
- Сохранение неизвестных ID3-кадров.
- Синхронизированный текст хранится в TXXX LYRICS_SYNCED; запись SYLT не заявлялась.
- Запись через SAF/MediaStore с временным файлом, проверкой содержимого и best-effort откатом.
- Проверки сохранения аудиоданных MP3 и unit-тесты.

## Статус проверок

Сборки CI проверяют компиляцию, unit-тесты и целостность/подпись APK в пределах настроенного workflow. Это не заменяет проверку пользовательских сценариев на физическом Android-устройстве.
