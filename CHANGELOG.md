# История изменений ChiyuriPlayer

Здесь собрана история функциональных изменений, перенесённая из прежней закрытой разработки в публичную документацию. Номера внутренних PR и сборок сохранены для прослеживаемости; это не означает, что прежний репозиторий является текущим каналом распространения.

## Сборка CI #172 — полноэкранное видео

**Статус:** сборка прошла CI; APK был собран как debug-вариант для arm64-v8a.

- Добавлен полноэкранный режим видео.
- Обычный и полноэкранный интерфейсы используют один экземпляр PlayerView.
- В полноэкранном режиме скрываются системные панели; их можно временно показать жестом.
- Добавлена кнопка выхода из полноэкранного режима.
- Кнопка «Назад» также закрывает полноэкранный режим.
- Панель основного интерфейса скрывается на время полноэкранного просмотра.

## Изменения PR #3 — встроенные тексты песен, синхронизация и пресеты эквалайзера

- Добавлено чтение обычных и синхронизированных текстов песен из MP3: ID3 USLT, ID3 SYLT с временными метками в миллисекундах и TXXX-поле LYRICS_SYNCED.
- Добавлено чтение текстов из FLAC Vorbis comments (LYRICS и LYRICS_SYNCED).
- Добавлено чтение текстов из M4A/MP4 (©lyr и freeform ---- / LYRICS_SYNCED).
- Экран текстов песен сначала использует встроенные данные, а затем может переходить к LRCLIB, если подходящего встроенного текста нет.
- Добавлена индивидуальная поправка синхронизации для URI трека: диапазон ±10 000 мс, шаг управления 100 мс.
- Добавлены семь пресетов эквалайзера: Flat, Bass, Pop, Rock, Classical, Jazz и Vocal. При ручном изменении настроек выбранный пресет сбрасывается.
- Добавлены unit-тесты для парсинга встроенных текстов, пресетов и поправки синхронизации.

**Известное ограничение:** чтение M4A/MP4 ограничено первыми 16 МиБ файла. Если атом moov расположен в конце большого файла, встроенный текст может быть не найден. Для полного решения требуется чтение контейнера с произвольным позиционированием без загрузки всего файла в память.

## Изменения PR #1 — запись ID3-метаданных MP3

- Добавлена запись ID3-кадров TIT2 (название), TPE1 (исполнитель), TALB (альбом), TDRC (год), USLT (текст песни) и APIC (обложка).
- Неизвестные ID3-кадры сохраняются при обновлении тегов.
- Синхронизированный текст сохраняется в TXXX LYRICS_SYNCED; запись в SYLT в этой реализации не заявлялась.
- Добавлена запись через SAF/MediaStore с временным файлом, проверкой содержимого и best-effort откатом при ошибке.
- Добавлены проверки, что аудиоданные MP3 не меняются при обновлении тегов.
- Добавлены unit-тесты.

## Примечания о статусе сборок

- Внутренняя сборка #172 успешно прошла доступные этапы CI: unit-тесты, assembleDebug, проверку подписи APK и публикацию CI-артефакта.
- Это была **debug-сборка**, а не production/release APK.
- Прохождение CI не заменяет тестирование на реальном Android-устройстве.
- Более ранние функции и возможности приложения не перечисляются здесь как гарантированные, если их фактическая реализация отдельно не подтверждена.
