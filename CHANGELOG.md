# История изменений ChiyuriPlayer

## 0.5.1 — 10 ноября 2026

- Исправлены все замечания Android Lint: итоговый отчёт — **No issues found** (0 ошибок, предупреждений и подсказок).
- Приложение переведено на Android 17 / API 37, с адаптацией интерфейса к edge-to-edge и свободной ориентации экрана.
- Добавлена поддержка разрешения локальной сети Android 17: запрос появляется только при воспроизведении адресов локальной сети.
- Защищён экспортируемый MediaSessionService: подключение разрешено доверенным системным медиаконтроллерам и самому приложению; управление через Bluetooth и Android Auto сохранено.
- Обновлены Gradle до 9.9.0 и AndroidX Lifecycle / WorkManager; добавлена ABI x86_64.
- Обновлены иконки приложения: adaptive icon с отдельными foreground и monochrome слоями; удалены дублирующиеся растровые варианты.
- Применены AndroidX KTX и Compose-рекомендации, удалены избыточные проверки SDK и ненужные ресурсы.
