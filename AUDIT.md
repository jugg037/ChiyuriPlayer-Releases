## Замечания и технический долг

1. **Устаревшие API Kotlin/Android.** Компилятор сообщает об использовании deprecated `android.media.audiofx.Virtualizer`, нескольких зеркальных Compose-иконок и `createTempDir()` в тестах. Сборку это не блокирует, Android Lint при этом сообщает ноль замечаний. Рекомендуется заменить API на актуальные аналоги.
2. **Предупреждения Gradle.** В журнале указано, что используются deprecated Gradle features, несовместимые с будущим Gradle 10. Следует выполнить отдельную миграционную проверку с `--warning-mode all`.
3. **GitHub Actions runtime.** В журнале Actions есть предупреждение о принудительном переходе используемых actions с Node.js 20 на Node.js 24, а также предупреждение о прекращении обновлений для `actions/setup-java@v4`. Нужно обновить actions до поддерживаемых версий и проверить совместимость workflow.
4. **Архитектура исходников.** Приложение собирается из базового ZIP с последовательным применением 47 patch scripts. Это работает в CI, но затрудняет обычное ревью полного конечного дерева исходников и повышает риск конфликтов между патчами. Долгосрочно предпочтительно хранить конечный Android-проект в репозитории как обычное дерево исходников.
5. **Проверка на устройстве не выполнена.** Реальная запись метаданных через SAF/MediaStore, установка обновления поверх предыдущей версии, DLNA discovery на разных маршрутизаторах, воспроизведение сетевых потоков, Bluetooth/Android Auto, датчик ориентации и качество аудио требуют физического устройства.
