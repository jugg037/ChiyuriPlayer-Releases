# ChiyuriPlayer

**ChiyuriPlayer** — Android-аудио- и видеоплеер. Этот публичный репозиторий предназначен для разработки, документации и распространения релизов проекта.

## Текущий целевой релиз

**Версия 0.2.0** — функциональное обновление в подготовке. Планируемые направления:

- Проверка обновлений и загрузка APK непосредственно внутри плеера.
- Управление субтитрами и аудиодорожками, улучшенные настройки видео.
- Улучшения эквалайзера, басов и усиления громкости.
- Развитие медиатеки, поиска, сортировки, очереди, избранного и плейлистов.
- Улучшения текстов песен, обложек и редактирования метаданных.
- Динамическое оформление, мини-плеер и визуализатор.
- Дополнительные тесты и повышение стабильности.

Это план, а не перечень уже готовых функций. Фактически реализованные изменения будут отмечаться в [CHANGELOG.md](CHANGELOG.md).

## Подготовка исходников и сборки

В репозиторий добавлен workflow .github/workflows/android.yml. Чтобы запустить сборку, загрузите в корень репозитория архив ChiyuriPlayer-0.2.0-source-prep.zip (через Add file → Upload files). Workflow извлечёт исходники, запустит unit-тесты, соберёт подписанный APK и создаст релиз v0.2.0.

Перед первой сборкой владелец репозитория должен добавить в Settings → Secrets and variables → Actions секреты постоянного ключа подписи:

- ANDROID_SIGNING_KEY_BASE64 — содержимое keystore в Base64;
- ANDROID_KEYSTORE_PASSWORD — пароль keystore;
- ANDROID_KEY_ALIAS — alias ключа;
- ANDROID_KEY_PASSWORD — пароль ключа.

Используйте один и тот же keystore для всех последующих версий. Не публикуйте сам keystore и не добавляйте его в Git.

## Уже подтверждённые функции исходной кодовой базы

- Запись ID3-метаданных MP3: название, исполнитель, альбом, год, текст песни и обложка.
- Чтение встроенных текстов из MP3, FLAC и M4A/MP4.
- Индивидуальная поправка синхронизации текста песни.
- Семь пресетов эквалайзера.
- Полноэкранное воспроизведение видео.

Подробности и ограничения — в [истории изменений](CHANGELOG.md).

## Установка

1. Откройте раздел [Releases](https://github.com/jugg037/ChiyuriPlayer-Releases/releases).
2. Скачайте APK последнего релиза.
3. Откройте файл на Android и подтвердите установку.

Для версии 0.2.0 используется новая подпись APK. Старую установленную сборку потребуется удалить перед первой установкой 0.2.0; локальные данные приложения могут быть потеряны. После установки 0.2.0 обновления должны подписываться тем же ключом.

Android требует системного подтверждения установки APK. Обычное приложение не может устанавливать обновления полностью незаметно.
