# ChiyuriPlayer

**ChiyuriPlayer** — Android-аудио- и видеоплеер для Android 10+. Этот публичный репозиторий содержит исходный архив, сценарии подготовки исходников, CI-сборку, документацию и опубликованные APK.

## Актуальный релиз: 0.5.9

- **Версия приложения:** 0.5.9
- **versionCode:** 345
- **Релиз:** https://github.com/jugg037/ChiyuriPlayer-Releases/releases/tag/v0.5.9
- **APK:** https://github.com/jugg037/ChiyuriPlayer-Releases/releases/download/v0.5.9/app-release.apk
- **SHA-256:** `f8a5fccf0f17de3e9bf83a58a81277dffa479958440fb3d13cc86a9affcaceaf`

В версии 0.5.9 добавлено обнаружение DLNA/UPnP медиасерверов в локальной сети через SSDP. Обнаружение ограничено локальными адресами; клиент не загружает содержимое найденных серверов и не выполняет произвольный HTTP-запрос к ним. Добавлены необходимые разрешения Android 17 / API 37 и Wi-Fi multicast permissions.

## Основные возможности проекта

- Аудио- и видеовоспроизведение на базе Android Media3, фоновое воспроизведение и системные медиакнопки.
- Мини-плеер, очередь воспроизведения, плейлисты, избранное и медиатека.
- Эквалайзер, аудиоэффекты и усиление уровня плеера до 200% от исходного уровня.
- Встроенные тексты песен, поиск текстов и редактор метаданных.
- Внешние субтитры SRT, VTT, ASS/SSA и TTML.
- Сетевые источники и обнаружение DLNA/UPnP в локальной сети.
- Центр обновлений с проверкой SHA-256 и подписи APK, отслеживанием загрузки и отменой.
- Динамическое оформление Chiyuri и фирменный Chiyuri Blood Loader.

## Сборка и публикация

Workflow находится в `.github/workflows/android.yml`. Он извлекает исходный проект из `ChiyuriPlayer-0.2.0-source-prep.zip`, последовательно применяет сценарии `.github/scripts/patch_*.py`, выполняет проверки интеграции, unit-тесты и Android Lint, собирает подписанный release APK, проверяет его подпись и версию и публикует GitHub Release.

Для подписания используется постоянный keystore. Не публикуйте keystore или пароли и не меняйте ключ между обновлениями: Android должен распознавать последующие APK как обновления установленного приложения.

Необходимые GitHub Actions secrets:

- `ANDROID_SIGNING_KEY_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

## Установка

1. Откройте [последний релиз](https://github.com/jugg037/ChiyuriPlayer-Releases/releases/latest).
2. Скачайте `app-release.apk`.
3. Откройте APK на Android и подтвердите системную установку.

Для обновления поверх существующей версии подпись APK должна совпадать с установленной. Android в любом случае требует системного подтверждения установки.

## Проверки и известные ограничения

Успешные CI-проверки подтверждают прохождение автоматизированных проверок исходников, unit-тестов, Android Lint, сборки и подписи APK. Они не заменяют тестирование на реальном устройстве. В частности, поведение SAF/MediaStore при перезаписи файлов, совместимость сетевых серверов и воспроизведение потоков, работа DLNA в разных Wi-Fi сетях, аудиоустройства и датчики ориентации требуют практической проверки на Android.

Подробный отчёт по проверке релиза находится в [AUDIT.md](AUDIT.md). История текущего релиза — в [CHANGELOG.md](CHANGELOG.md).
