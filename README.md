# ChiyuriPlayer

**ChiyuriPlayer** — Android-аудио- и видеоплеер. Этот публичный репозиторий является официальной страницей проекта и каналом распространения релизов и обновлений.

> Исходный код проекта на этом этапе не публикуется. Здесь размещаются сведения о проекте, история изменений, инструкции и готовые сборки.

## Загрузки

- **Последняя версия:** пока не опубликована в этом репозитории.
- **Релизы:** [Открыть Releases](https://github.com/jugg037/ChiyuriPlayer-Releases/releases)
- **История изменений:** [CHANGELOG.md](CHANGELOG.md)

Когда первая сборка будет опубликована здесь, APK можно будет скачивать непосредственно по ссылке на релиз. Приложение сможет проверять этот публичный канал обновлений и загружать APK внутри плеера, без перехода на сайт.

## Что уже реализовано

По состоянию на внутреннюю сборку CI **#172**:

- Запись ID3-метаданных MP3: название, исполнитель, альбом, год, обычный и синхронизированный текст песни, обложка.
- Чтение встроенных текстов песен из MP3 (USLT, SYLT и TXXX), FLAC (Vorbis comments) и M4A/MP4.
- Синхронизация текста песен с индивидуальной поправкой времени для трека.
- Семь пресетов эквалайзера: Flat, Bass, Pop, Rock, Classical, Jazz и Vocal.
- Полноэкранное воспроизведение видео с системными панелями, скрываемыми на время просмотра, и возвратом по кнопке «Назад».

Состав функций может меняться от сборки к сборке. Подробности и известные ограничения указаны в [истории изменений](CHANGELOG.md).

## Установка

1. Откройте раздел [Releases](https://github.com/jugg037/ChiyuriPlayer-Releases/releases).
2. Скачайте APK последнего стабильного релиза.
3. Откройте файл на Android и подтвердите установку. Android может запросить разрешение на установку приложений из выбранного источника.

Обычная установка обновления поверх предыдущей версии требует, чтобы APK был подписан тем же ключом. Не удаляйте установленное приложение перед обновлением, если хотите сохранить его данные.

## Обновления внутри приложения

Планируется публичный HTTPS-манифест обновлений и загрузка APK непосредственно из ChiyuriPlayer. Android всё равно показывает системное подтверждение установки: обычное приложение не может незаметно установить обновление самостоятельно.
