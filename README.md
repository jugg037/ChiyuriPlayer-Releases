**ChiyuriPlayer** — Android-аудио- и видеоплеер. Этот публичный репозиторий используется для исходной сборки, документации и распространения релизов.

## Что входит в текущую работу

Проект развивается по направлениям:

- Аудио- и видеовоспроизведение на базе Android Media3.
- Фоновое воспроизведение и системные медиакнопки.
- Центр обновлений с проверкой SHA-256 и сертификата подписи APK.
- Фоновая загрузка обновления с прогрессом и отменой из приложения или системного уведомления.
- Редактирование тегов и встроенных текстов песен.
- Подключение внешних субтитров SRT, VTT, ASS/SSA и TTML.
- Безопасная проверка версии и подписи APK, реактивное отслеживание загрузки.
- Безопасная загрузка обложек, кэш текстов песен и восстановление параметров очереди.
- Дополнительное усиление громкости плеера — до +200% (до 300% общей громкости, 3x).
- Поддержка частичного доступа к видео на Android 14+ и ограниченный импорт M3U/M3U8.
- Поиск текстов по нескольким внешним каталогам и отображение синхронизированного текста в мини-плеере.
- Добавление текущего трека в существующий или новый плейлист из мини-плеера, а также удаление его из выбранного плейлиста без удаления самого аудиофайла.
- Эквалайзер, аудиоэффекты, медиатека и динамическое оформление.
- Фирменный Chiyuri Blood Loader: круговое заполнение эмблемы кровавой текстурой, световая волна и режим неопределённого прогресса.

Наличие кода и успешная сборка не означают, что все сценарии уже проверены на реальном устройстве. Проверки CI и известные ограничения фиксируются в CHANGELOG.md; фактическое поведение Android/SAF/уведомлений требует отдельного тестирования на устройстве.

## Сборка и публикация

Workflow находится в .github/workflows/android.yml. Он извлекает исходный проект из ChiyuriPlayer-0.2.0-source-prep.zip, применяет поддерживаемые проектом изменения, запускает unit-тесты, собирает подписанный release APK, проверяет подпись и версию, затем публикует APK в GitHub Releases.

Для подписания используется постоянный keystore. Не публикуйте keystore или пароли и не меняйте ключ между обновлениями: Android должен распознавать последующие APK как обновления установленного приложения.

Необходимые GitHub Actions secrets:

- ANDROID_SIGNING_KEY_BASE64
- ANDROID_KEYSTORE_PASSWORD
- ANDROID_KEY_ALIAS
- ANDROID_KEY_PASSWORD

## Установка

1. Откройте Releases.
2. Скачайте app-release.apk из последнего релиза.
3. Откройте APK на Android и подтвердите системную установку.

Для обновления поверх существующей версии подпись APK должна совпадать с установленной. Android в любом случае требует системного подтверждения установки.
